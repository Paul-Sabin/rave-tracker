- `ra-tracker/tests/test_email_sender.py` created: 9 unit tests covering success (201→True), failure (non-2xx→False, exception→False), the Pitfall-1 misconfiguration case (SMTP password present but no API key → `False` and zero HTTP calls), `is_email_configured()` in both states, all-five-senders API routing, all-five-senders failure propagation, and a log-scrubbing assertion that the API key value never appears in `caplog.text`.

- No fallback, default key, or auto-switch-back-to-SMTP was added despite `is_email_configured()` becoming stricter - this is the plan's explicit, intended fail-safe, not a regression to work around.
